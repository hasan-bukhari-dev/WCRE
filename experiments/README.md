# WCRE Experiments

This directory contains isolated experiments used to test assumptions before
they become part of the WCRE architecture.

Experiments should answer one narrowly defined technical question.

Each experiment should document:

1. Question
2. Hypothesis
3. Method
4. Result
5. Evidence
6. Conclusion

Failed experiments are retained when they provide useful information about
Windows behavior or eliminate an architectural approach.

## Initial experiments

- PSS process capture
- virtual-address enumeration
- thread context capture
- exact-address allocation
- process-memory persistence
- thread-state restoration
- handle reconstruction
